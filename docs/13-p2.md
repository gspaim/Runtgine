## G-30 — Cancel / timeout / retry / concorrencia

**Status: CONFIRMED** (variante B)

| Tema | Corte |
|---|---|
| Timeout | Shell `timeout_ms`; Runner cancela step → `runtime.timeout` |
| Cancel | `CancelRun(run_id)` real: context cancel + estado `cancelled` |
| Retry | Retry automatico **configuravel por step** (+ retry 1x parse JSON LLM) |
| Concorrencia | Multi-run + `max_concurrent_runs` (default sugerido: 4) |
| Step fail | Apos esgotar retries, step fail → run fail |
